# 代码结构与数据流

本项目是 React + TypeScript 的纯前端应用。网站可以直接由 GitHub Pages 托管，手账内容保存在访问者自己的浏览器中。

## 模块划分

- `src/app/App.tsx`：启动、读取文档、兼容旧数据和读取失败后的重试。
- `src/app/JournalApp.tsx`：书架与编辑器的协调层，管理页面、选择、历史记录、拖动和保存。
- `src/domain/journal.ts`：页面、素材、图形、胶带、文字样式等共用类型。
- `src/config/journal.ts`：默认页面、纸张、颜色和组件名称。
- `src/features/canvas/`：手绘、橡皮、胶带遮罩和组件锁定。
- `src/features/images/`：图片裁剪、边界计算、去背景、描边和贴纸效果。
- `src/features/text/`：字号输入、富文本转换与样式清理。
- `src/features/audio/`：统一音效开关和音量面板。
- `src/features/books/`：书本封面、打开动画和交互风铃。
- `src/features/weather/`：页面与书架的雨、雪、白云和阳光效果。
- `src/storage/`：文档和媒体存储、偏好设置、旧版本迁移。
- `src/assets/`：代码生成的默认风景素材。
- `src/styles/`：基础界面、编辑控件、打开书本和翻页样式。

## 编辑和保存

画布交互只在必要时记录一次操作历史。拖动时使用 `requestAnimationFrame` 和独立位移属性更新当前组件，松手后将最终坐标写入页面。图片的编辑框单独呈现，跟随选中的图片移动，不改变素材的实际图层顺序。

文档变化后，自动保存会等待 450 毫秒。存在拖动、旋转或缩放操作时，保存会延后到操作结束，以免大图片文档的复制干扰鼠标响应。手动保存和返回书架会等待存储完成。

## 浏览器数据库

| 数据               | IndexedDB 数据库              | 对象仓库  |
| ------------------ | ----------------------------- | --------- |
| 手账书架和完整页面 | `yepaper-library-v2`          | `library` |
| 导入图片的原始文件 | `journal-image-assets-v1`     | `images`  |
| 每页的背景音乐     | `journal-background-music-v1` | `tracks`  |

页面通过 `asset:<id>` 引用原始图片；显示时转换为临时对象地址。抠图结果、手绘结果和胶带擦除轨迹属于页面数据。每页音乐保存的是文件标识和名称，音量与声音开关属于全局偏好。数据库名称和旧字段在重构时保持兼容，避免丢失已有浏览器文档。

`localStorage` 保存天气、音量等偏好，并负责读取旧版本迁移数据。文档写入按顺序执行，避免较早的自动保存覆盖较新的手动保存。

## 部署路径

开发模式使用 `/`，`github-pages` 模式使用 `/digital-journal/`。公共音频通过 `import.meta.env.BASE_URL` 加载。案例视频和封面在 `public/demo/`，构建时自动复制到 `dist/demo/`。

浏览器存储按来源隔离，因此本地开发地址中的手账不会自动出现在 GitHub Pages 地址中。网站不提供账号或云同步。
